# PHOTON ROAD — diffractive optical processing of Ca II 854.2 nm Stokes V

Code and data products for the paper

> *What does a diffractive optical network compute? Matched-filter limits for weak-field detection in solar spectropolarimetry*, submitted to Applied Optics.

The code simulates weak-field Stokes V profiles of Ca II 854.2 nm degraded by three instrument models (IBIS/DST, CRISP/SST, ViSP/DKIST). It also models coherent 4f processors with one Fourier-plane mask: phase-only or amplitude-and-phase, trained or designed. These are compared with the whitened matched filter through the detection limit a₅₀ at 5% false-alarm probability.

## Requirements

Python ≥ 3.10 and the packages in `requirements.txt`:

```
pip install -r requirements.txt
```

A GPU is optional. All scripts used in the paper run on a CPU.

## Repository layout

| Folder | Contents |
|---|---|
| `Src/` | physics (Stokes synthesis, instrument degradation), optics (4f system, pupil), models, training and evaluation utilities |
| `Scripts/` | numbered scripts; each writes a JSON report to `Outputs/Reports/` |
| `CheckPoints/` | trained masks used in the paper (`modelo_d2nn_optico_v2.pt`, `modelo_d2nn_complexo_v2.pt`) and the three hybrid networks ablated in Fig. 2 |
| `Outputs/Reports/` | JSON reports from which the paper's tables and figures are drawn |
| `docs/` | working notes (in Portuguese) with the full record of tests and decision criteria |

## Reproducing the paper

All scripts are run from the repository root. The profiles are generated with fixed seeds, so the results are reproducible.

| Paper item | Script |
|---|---|
| Fig. 2 (ablation of hybrid networks) | `python Scripts/61_ablacao_optica.py` |
| Trained phase-only mask with field stop (checkpoint) | `python Scripts/67_d2nn_optica_diafragma.py` |
| Trained amplitude-and-phase mask (checkpoint) | `python Scripts/74_d2nn_complexa.py` |
| Fig. 5 (ViSP, fixed masks) | `python Scripts/73_mascara_visp.py` |
| Table 2, Fig. 4, quantization, light budget | `python Scripts/75_referencias_artigo_b.py` (~11 min) |
| Designed whitened masks, Figs. 4 and 6 | `python Scripts/76_mascara_branqueada.py` (~4 min) |
| Appendix A (estimator of a₅₀) | `python Scripts/70_estimador_fisico.py` |
| Supplement 1: Doppler shifts, inclined fields | `python Scripts/68_doppler.py`, `python Scripts/71_inclinacao.py` |
| Supplement 1, S3: sensitivity of the CRISP limits to the spectral grid | `python Scripts/97_sensibilidade_grade_crisp.py` (seconds) |
| All figures from the reports and checkpoints | `python Scripts/77_figuras_artigo_b.py` (< 1 min) |

Scripts 75–77 only need the two mask checkpoints, and script 61 the three hybrid checkpoints; none of them retrains.

## Data

All profiles are synthetic and are generated by the code. No observational data are needed to reproduce the paper.
The CRISP grid of 2024 October 8 used in Supplement 1, S3, is written in `Scripts/97_sensibilidade_grade_crisp.py`
(read from the WCS-TAB of the SST archive files). The confirmation of the CRISP noise model with those observations,
also quoted in S3, comes from the observational analysis of a companion paper and is not part of this repository.
